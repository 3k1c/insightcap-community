Frequently Asked Questions

Is InsightCAP free?

Yes. InsightCAP is completely free to download and use from the GitHub releases page.

Does it support Mac or Linux?

InsightCAP is currently focused on providing the best possible native experience for Windows.

How is it different from cloud note apps?

InsightCAP is local-first. We focus on automated capture, extraction, search, and export, completely independent of hosted cloud workspaces.
