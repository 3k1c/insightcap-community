回顧本次對話的執行過程，找出可改進之處，並自動更新相關 skill 或 CLAUDE.md。

## 執行步驟

**1. 回顧本次對話**
檢視以下面向：
- 哪些步驟走了彎路或需要重做？
- 哪些假設是錯的，導致讀了不必要的檔案？
- 哪個 skill 被執行但效果不符預期？
- 使用者有沒有糾正我的方向或做法？

**2. 分類改進項目**

| 類型 | 說明 | 對應行動 |
|------|------|----------|
| Skill 邏輯錯誤 | 某個 /skill 的步驟有誤或不完整 | 更新該 skill 檔案 |
| 核心規則缺漏 | CLAUDE.md 沒有覆蓋到的行為規範 | 更新 CLAUDE.md |
| Token 浪費模式 | 反覆犯同樣的高消耗操作 | 更新 /token-guard |
| 新的常見任務 | 本次任務未來會重複出現 | 建立新 skill |

**3. 輸出改進清單**
格式：
```
【自我改進報告】

發現的問題：
- [問題描述] → [根本原因]

建議改動：
1. 更新 .claude/commands/xxx.md：[具體修改內容]
2. 更新 CLAUDE.md：[具體新增規則]
3. 新建 .claude/commands/yyy.md：[用途說明]
```

**4. 詢問確認**
列出所有建議改動後，問：「是否套用以上改進？」
使用者確認後，逐一寫入對應檔案。
每修改一個檔案後等確認再繼續下一個。

## 注意事項
- 只改有明確根據的問題，不做假設性優化
- 不刪除現有規則，只補充或修正
- 每次改動附上本次對話的具體案例作為依據
