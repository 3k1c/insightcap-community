# InsightCAP Community v0.9.1-beta.1

This Community Edition beta update focuses on the editor table experience and
release metadata alignment.

## Release Status

Status: public beta prerelease.

This release note is intended to support a GitHub Release. The installer should
be uploaded as a GitHub Release asset and should not be committed directly to
Git history.

## Installer

- Expected file name: `InsightCAP_0.9.1-beta.1_x64-setup.exe`
- Platform: Windows x64
- Installer type: NSIS
- File size: to be published with the GitHub Release asset
- SHA256: to be published with the GitHub Release asset

## What's Changed

- Refined the AI text editor table floating menu with clearer table-specific
  controls for inserting rows, inserting columns, merging cells, splitting
  cells, toggling header rows, and deleting table elements.
- Updated table action icons to better match familiar office-editor table
  controls.
- Improved wide-table handling so large tables stay inside the editor layout and
  can scroll horizontally instead of expanding the whole editor pane.
- Aligned table resize behavior with the upstream Tiptap/AiEditor approach by
  using native table resizing and a passive resize handle style.
- Added shared popup-positioning helpers and tests so editor floating menus stay
  inside the editor bounds.
- Updated application version metadata to `0.9.1-beta.1` across the frontend,
  Tauri configuration, and Rust package metadata.
