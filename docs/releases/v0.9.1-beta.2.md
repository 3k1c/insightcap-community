# InsightCAP Community v0.9.1-beta.2

This Community Edition beta update focuses on the AI text editor popup behavior
and release metadata alignment.

## Release Status

Status: public beta prerelease.

This release note is intended to support a GitHub Release. The installer should
be uploaded as a GitHub Release asset and should not be committed directly to
Git history.

## Installer

- Expected file name: `InsightCAP_0.9.1-beta.2_x64-setup.exe`
- Platform: Windows x64
- Installer type: NSIS
- File size: pending release asset upload
- SHA256: pending release asset upload

## What's Changed

- Fixed AI text editor popup positioning so the AI loading and result panel
  follows the selected text using the same measured positioning approach as the
  text formatting popup menu.
- Prevented completed AI suggestions from being dismissed by outside clicks
  before the user explicitly chooses Apply, Retry, Discard, or Close.
- Kept AI suggestion actions anchored to the editor selection while staying
  within the visible editor bounds.
- Updated application version metadata to `0.9.1-beta.2` across the frontend,
  Tauri configuration, and Rust package metadata.
