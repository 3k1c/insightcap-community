# InsightCAP Community v0.9.2-beta.1

This beta expands InsightCAP Community bot workflows from Telegram-only usage to
multi-communication-platform support.

## Highlights

- Added WhatsApp support through a local WhatsApp Bridge.
- Added Weixin support through the iLink protocol.
- Added WeCom support for enterprise WeCom assistant conversations.
- Localized bot settings copy for Traditional Chinese, Simplified Chinese, and
  English.
- Fixed bundled WhatsApp Bridge startup in the installed Windows app.
- Runs WhatsApp Bridge commands without opening cmd windows.

## Supported Bot Channels

- Telegram: capture, reminders, knowledge Q&A, and project or conversation
  commands.
- WhatsApp: capture and assistant conversations through the local Bridge.
- Weixin: personal Weixin integration through iLink.
- WeCom: enterprise WeCom assistant integration.
