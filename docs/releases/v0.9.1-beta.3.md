# InsightCAP Community v0.9.1-beta.3

This Community Edition beta update fixes Bilibili short-link imports, cleans up
stale tag indexes, and aligns release metadata for the next public prerelease.

## Release Status

Status: public beta prerelease.

This release note is intended to support a GitHub Release. The installer should
be uploaded as a GitHub Release asset and should not be committed directly to
Git history.

## Installer

- Expected file name: `InsightCAP_0.9.1-beta.3_x64-setup.exe`
- Platform: Windows x64
- Installer type: NSIS
- File size: pending release asset upload
- SHA256: pending release asset upload

## What's Changed

- Fixed Bilibili `b23.tv` short-link imports so they resolve to the canonical
  Bilibili video URL before subtitle extraction.
- Prevented Bilibili short links from falling back to generic webpage scraping,
  which could store unreadable imported content.
- Added tag index cleanup so tags from deleted sources or chunks are removed
  when they are no longer referenced.
- Recounts tag usage from active sources, captures, and memory chunks before
  showing the repository tag list.
- Refreshes the repository tag list after deleting or updating source content.
- Updated application version metadata to `0.9.1-beta.3` across the frontend,
  Tauri configuration, and Rust package metadata.
