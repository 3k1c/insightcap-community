# Daily Digest Skill

## 用途
每日自動彙整當天（或指定日期範圍）擷取的知識片段，生成一份簡潔的每日回顧報告。
幫助用戶快速回顧當天的學習成果，並發現跨主題的關聯。

## 模型建議
使用 `summaryModel`（摘要模型，跟隨設定）。

## Prompt 格式

```
你是一個個人知識助手，請根據以下今日擷取的內容生成每日知識回顧。

日期：{date}
擷取項目數：{item_count}
今日內容：
{items_list}

請生成一份結構化的每日回顧，包含：

## 今日主題
用 2～3 句話描述今天涉及的主要主題和領域。

## 重點知識
列出 3～5 個今日最值得記住的知識點（每點一行，以 • 開頭）。

## 跨領域連結
若發現不同來源之間有關聯或對比，簡短指出（若無則省略此節）。

## 明日建議
根據今日內容，建議 1～2 個可以深入探索的方向。

語言：繁體中文
風格：簡潔專業，避免廢話
```

## 觸發邏輯
- 每日定時任務（建議 22:00 或應用程式關閉前）觸發
- 也可由使用者在 Timeline 頁手動觸發「生成今日回顧」
- `items_list`：當日所有 chunks 的標題 + 前 150 字元摘要，換行拼接（最多 30 條）
- `date`：格式 `YYYY年MM月DD日`

## 輸出處理
將生成的 Markdown 文字儲存為特殊類型的知識片段：
- `knowledge_type`: `digest`
- `tags`: `["每日回顧", "{YYYY-MM-DD}"]`
- `space_id`: 使用者設定的「日記/回顧」Space，若未設定則存入收件匣

## 錯誤處理
若當日擷取項目少於 3 條，不觸發生成，改以系統通知提示「今日擷取內容較少，建議明日再生成回顧」。
