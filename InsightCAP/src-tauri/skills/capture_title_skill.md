# Capture Title Skill

## 用途
為擷取的內容（網頁、檔案、剪貼板文字）自動生成簡潔且具描述性的標題。
當來源沒有明確標題或標題過長、無意義時觸發。

## 模型建議
使用 `contentProcessorLlm`（後台處理模型），無需高品質生成，優先速度。

## Prompt 格式

```
你是一個專業的內容標題生成器。根據以下內容片段，生成一個簡潔、精準的標題。

規則：
- 標題長度：10～30 個中文字（或等長英文）
- 語言：與內容主要語言一致
- 風格：資訊性標題，不用句號結尾
- 禁止：不要加引號、不要重複「標題：」等前綴

內容類型：{type}
內容摘要：
{content}

請直接輸出標題，不要任何說明。
```

## 觸發邏輯
- `type` 可為：`webpage`、`file`、`text`、`screenshot`
- `content` 取前 500 字元的純文字

## 輸出處理
直接取回傳文字，trim 後作為 `source.title`
