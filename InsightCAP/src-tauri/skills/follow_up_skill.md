# Follow-up Skill

## 用途
在 AI 對話回覆後，根據對話脈絡自動建議 3 個延伸問題，引導用戶深入探索主題。
顯示在對話回覆下方作為快速點擊的建議按鈕。

## 模型建議
使用 `chatLlm`（對話模型），保持與主對話一致的理解上下文。

## Prompt 格式

```
根據以下對話的最後一輪，生成 3 個用戶可能想繼續追問的問題。

對話摘要：
{conversation_context}

AI 最後回覆：
{last_assistant_message}

要求：
- 每個問題獨立一行
- 問題長度：15～40 個字
- 方向多樣：可深入細節、可拓展相關主題、可請求實際範例
- 語言：與對話語言一致（中文對話用繁體中文）
- 格式：只輸出 3 行問題，不加編號、不加引號、不加任何說明

輸出範例：
這個方法在大規模數據集上的效能如何？
有沒有更簡單的替代方案適合初學者？
能給我一個實際的程式碼範例嗎？
```

## 觸發邏輯
- 每次 AI 串流回覆完成後觸發（非阻塞，背景執行）
- `conversation_context`：最近 4 輪對話的摘要（user/assistant 交替）
- `last_assistant_message`：最後一條 AI 回覆前 600 字元

## 輸出處理
按換行分割，取前 3 個非空字串，顯示為建議問題按鈕。
點擊後直接填入輸入框並送出。

## 錯誤處理
若生成失敗或格式不符，靜默略過，不顯示建議按鈕。
